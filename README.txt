OLD LENS PORTFOLIO
1. Unzip the folder and double-click index.html (needs internet for fonts and animation libraries).
2. Edit text in index.html. Contact details, experience and certificates are already filled in.
3. Add photos: put .webp files in images/full (up to 2400px) and images/thumb (900px), then add them to photos.js.
4. Deploy free: drag the folder to Netlify, or push it to GitHub Pages.
